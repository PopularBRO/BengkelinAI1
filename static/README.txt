BENGKELINAI MULTI-PAGE WEBSITE

Cara menjalankan:
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan index.html dengan Live Server.

File utama:
- index.html: Beranda
- style.css: Desain global dan responsive
- script.js: Interaksi seluruh halaman
- assets/logo-bengkelinai.png: Logo asli, latar putih dihilangkan agar menyatu dengan header

Halaman: beranda, cara kerja, fitur, diagnosis foto, analisis suara, estimasi biaya, cari bengkel, panggil mekanik, tentang, FAQ, kontak, dashboard, garasi, riwayat, pengingat servis.

Fitur tambahan lokal:
- Garasi kendaraan menyimpan data melalui localStorage browser.
- Pengingat servis disimpan melalui localStorage browser.
- Riwayat aktivitas lokal.
- Navigasi antarhalaman memakai View Transitions pada browser yang mendukung dan fade fallback pada browser lain.

Catatan: Fitur diagnosis, analisis suara otomatis, pencarian bengkel dan pengiriman formulir masih berupa demo. Tidak ada backend atau AI API yang terhubung. Data garasi, pengingat, dan riwayat tersimpan lokal di browser perangkat.
